# Sistema-de-Cartao-de-Vacinacao

Projeto de Residência Tecnológica — Embarque Digital

Análise e Desenvolvimento de Sistemas · 1º Período

-----
Sobre o Projeto
-----

Este projeto é um sistema de gerenciamento de cartão de vacinação desenvolvido em linguagem C, como atividade prática da disciplina de Residência Tecnológica do programa Embarque Digital, voltado para os  do 1º período do curso de Análise e Desenvolvimento de Sistemas.

O sistema visa digitalizar e organizar o controle vacinal de pacientes, permitindo o cadastro de pessoas e vacinas, o registro de aplicações, a geração de alertas de doses pendentes e a emissão de relatórios — tudo via interface de terminal interativa.


✅ Funcionalidades
--------
🔹 1. Cadastro de Pacientes
Gerenciamento completo do perfil de cada paciente no sistema.
- Nome completo
- Data de nascimento
- CPF/identificador
- Sexo
- Telefone de contato
- Endereço

🔹 2. Cadastro de Vacinas
Catálogo das vacinas disponíveis para aplicação no sistema.
- Nome da vacina
- Fabricante
- Número de doses necessárias
- intervalo entre doses(dias)
- Validade do lote

 🔹 3. Registro de Aplicação de Vacinas
- ID do paciente
- ID da vacina
- Data de aplicação
- Número da dose (1ª, 2ª, reforço)
- Lote da vacina
- Nome do profissional responsável


 🔹 4. Consulta da Carteira de Vacinação
- 📋 Listar todas as vacinas já aplicadas
- ⏳ Mostrar doses pendentes e em atraso
- 📅 Exibir datas previstas para as próximas doses

🔹 5. Controle de Doses Pendentes
- 🔍 Identificar vacinas com doses em atraso
- 🧮 Calcular automaticamente a data da próxima dose
- ⚠️ Emitir alertas no terminal para o usuário

🔹 6. Busca e Filtros
Ferramentas de pesquisa para agilizar o atendimento.
- 🔎 Buscar paciente por nome ou CPF
- 💉 Filtrar histórico por tipo de vacina
- 📛 Listar todos os pacientes com vacinas atrasadas
